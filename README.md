# CryptoWire - Crypto News Aggregator

AI-curated crypto and blockchain news aggregator with trending stories and market sentiment

## Features

- Latest crypto news from 50+ sources
- Featured hero article section
- Trending stories sidebar with rankings
- Category filtering tabs
- Time-ago timestamps
- Market sentiment gauge visualization

## Tech Stack

- **Framework:** Next.js 16 (App Router, TypeScript)
- **UI:** shadcn/ui + Tailwind CSS
- **Animations:** Framer Motion
- **API:** CryptoCompare Free API
- **Deployment:** Vercel

🔗 **Live Demo:** [https://crypto-news-hub-zeta.vercel.app](https://crypto-news-hub-zeta.vercel.app)
